# Casa do Condutor — site institucional

Site institucional de página única, responsivo e em português (Brasil).

## Estrutura

- `index.html` — estrutura e conteúdo da página.
- `css/styles.css` — estilos, identidade visual e responsividade.
- `js/main.js` — menu móvel, cards interativos, FAQ e animações de entrada.
- `assets/` — logomarca, favicon e fotografias.

## Como visualizar

Abra `index.html` em um navegador moderno. Para desenvolvimento, recomenda-se servir a pasta com um servidor HTTP local (por exemplo, Live Server).

## Publicação

Envie o conteúdo completo desta pasta para a raiz pública do domínio, preservando os caminhos relativos (`css/`, `js/` e `assets/`).

## Observações

- O exame toxicológico não é divulgado como serviço disponível.
- Os contatos e informações institucionais permanecem conforme os materiais fornecidos.
- As fontes tipográficas são carregadas do Google Fonts; sem conexão, serão usadas fontes de fallback.
